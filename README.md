# 🏠 DHK House Hunt

A modern, responsive web application designed to streamline the property rental search experience. **DHK House Hunt** allows users to seamlessly browse, filter, and find real estate listings across prominent locations.

---

## 🛠️ Languages & Technologies Used

* **🐍 Python:** Powers the backend logic, handles data processing, and manages server-side property APIs or database integration.
* **🌐 HTML5:** Structures the semantic layout of the application, including property grids and interactive filter modules.
* **🎨 CSS3:** Handles custom responsive styling, modern UI component layouts (Flexbox/Grid), hover animations, and intuitive form designs.
* **⚡ JavaScript (ES6+):** Powers the client-side interaction, managing state changes for dynamic data filtering, search logic, and DOM manipulation.

---

## ✨ Features

* **🏢 Diverse Property Listings:** Browse through a variety of property types tailored to different needs (Apartments, Villas, Studios, Independent Houses, and Penthouses).
* **🔍 Advanced Filtering System:** Narrow down your search instantly using:
    * **💰 Price Range:** Dynamic budget adjustment (₹0 to ₹100,000+ per month).
    * **🛏️ Bedroom Count:** Filter configurations from 1 up to 6+ BHKs.
    * **🏠 Property Type:** Toggle specific categories to match your lifestyle.
* **📱 Responsive Layout:** Optimized user experience across mobile, tablet, and desktop viewports.
* **❤️ Favorites/Wishlist:** Keep track of your shortlisted properties with a built-in saved counter.

## 📂 Property Data Structure

The application natively manages dynamic real estate nodes containing details such as:

```json
{
  "title": "Modern 2BHK Apartment",
  "location": "Jubilee Hills, Hyderabad",
  "price": 35000,
  "type": "Apartment",
  "specs": {
    "beds": 2,
    "baths": 2,
    "area": "1200 sqft"
  }
}

```
